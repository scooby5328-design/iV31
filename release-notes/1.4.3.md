## What's new
- **Party comparison.** A new panel under the IV readout lets you compare several Pokémon side by side. Press **+ Add party member**, fill in its Summary screen, and a table lines up every member's IVs, totals and Hidden Power. The best value in each stat is underlined and each Pokémon's key stats are highlighted. **Copy from Summary screen** adds the Pokémon you entered above. Works in every game, including the DVs of Gen I and II.
- Compare up to **30** Pokémon in the desktop app on Windows, Mac and Linux. The web page on a phone compares up to **3**.

## Install
**Already have iv31 1.2.0 or newer (Windows, Mac or the Linux .tar.gz):** iv31 offers this update by itself. Click **Update now**.

**Linux with apt:** run `sudo apt update && sudo apt upgrade` in Terminal.

**Linux AppImage:** download the new **iv31-1.4.3-x86_64.AppImage** (ARM: **aarch64**) below.

**New to iv31:** see the install steps for your system in the [README](https://github.com/scooby5328-design/iV31#install).
