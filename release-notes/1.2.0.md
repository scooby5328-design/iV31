## What's new
- **Auto-updater.** A few seconds after iv31 starts, it checks GitHub for a newer version. If there is one, a bar shows what's new with **Update now**, **Skip this version** and **Later**. Updating downloads the new version, checks its SHA-256 fingerprint, installs it and restarts iv31, keeping your saved data.
- Click the version number in the top bar to check for updates any time. The automatic check can be turned off in the Guide.
- Tighter security: the app can only write its own app file and relaunch itself, and the page's Content Security Policy now works.

## Install
Download **iv31-Setup-1.2.0.exe.zip** below, right-click it, choose **Extract All**, then run the installer. If Windows shows "Windows protected your PC", click **More info → Run anyway**.

**Have 1.1.0 or older?** Install this one once. It installs over the old version and keeps your saved data, and from then on iv31 updates itself.
