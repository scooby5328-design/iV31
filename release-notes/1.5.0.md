## What's new
- **Complete updates in place.** When iv31 updates itself, it can now replace the program file too, not just the app inside it, right where iv31 is installed. It then restarts on its own. Future updates never need a separate installer.
- Updates download and check every file before touching anything, swap the new files in, keep the old program until the new one is running, then clean up.
- **Phones.** The iv31 web page opened on a phone now matches the free version of the upcoming Android app: one IV calculation at a time, and the EV table without wild locations. The desktop app still has everything for free.

## Install
**Windows, Mac or the Linux .tar.gz on 1.2.0 or newer:** iv31 offers this update by itself. Click **Update now**.

**Linux with apt:** `sudo apt update && sudo apt upgrade`

**AppImage:** download the new AppImage below.

**New to iv31:** see the install steps for your system in the [README](https://github.com/scooby5328-design/iV31#install).
