## What's new
- **Two main EVs per route:** the Routes tab and each route page now show the two EVs a route's Pokémon give most, most common first (for example **1. Speed 2. Sp. Def**), since each Pokémon trains two key stats.
- **Training one Pokémon:** pick a Pokémon in the IV Calculator and the Routes tab highlights its two key stats in yellow. Routes where both are the main EVs get a ★.

## Install
**Online:** open **scooby5328-design.github.io/iV31** (it updates by itself).

**Windows:** iv31 offers this update by itself. Click **Update now** and it installs through the installer.

**Mac or the Linux .tar.gz:** iv31 offers this update by itself. Click **Update now**.

**Linux with apt:** `sudo apt update && sudo apt upgrade`

**AppImage:** download the new AppImage below.
