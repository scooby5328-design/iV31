## What's new
- **Fits every screen better:** on small windows and laptops the red side panels shrink so the screen gets more room. On big monitors everything still scales up.
- **Tablets:** held upright, iPads and Android tablets now get the full-width layout with tabs on top instead of a narrow screen between the side panels.
- **Text size:** Ctrl (Cmd on Mac) + mouse wheel or a trackpad pinch now changes the size, along with the − and + keys and Ctrl + / Ctrl −. Sizes now go up to 175%. If a size is too big for the window, iv31 steps it down and goes back to your choice when there's room.
- **Phones:** the − and + size buttons are now in the top bar.
- **Android:** a large system font size no longer squashes the layout; iv31 starts at a matching size instead.
- **Desktop app:** the window opens a little shorter so it fits on 768-pixel-tall laptop screens.

## Install
**Online:** open **scooby5328-design.github.io/iV31** (it updates by itself).

**Windows:** iv31 offers this update by itself. Click **Update now** and it installs through the installer.

**Mac or the Linux .tar.gz:** iv31 offers this update by itself. Click **Update now**.

**Linux with apt:** `sudo apt update && sudo apt upgrade`

**AppImage:** download the new AppImage below.

**Android:** this update changes the app itself, so it needs the new app build.
