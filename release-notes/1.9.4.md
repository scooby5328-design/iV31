## What's new
- **New app icon:** iv31's icon is now the field terminal itself: the red shell with its blue screen showing IV/31, the green power light, the D-pad and the two black buttons. Small versions are simplified so they stay readable in menus and browser tabs.

## Install
**Online:** open **scooby5328-design.github.io/iV31** (it updates by itself). If you added it to your home screen, remove it and add it again to see the new icon.

**Windows, Mac or the Linux .tar.gz on 1.2.0 or newer:** iv31 offers this update by itself. Click **Update now**. The window shows the new icon straight away. The Start menu and desktop shortcuts on Windows, and the Dock icon on Mac, change when you install with the new installer below.

**Linux with apt:** `sudo apt update && sudo apt upgrade`

**AppImage:** download the new AppImage below.
