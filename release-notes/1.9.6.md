## What's new
- **Game picker matches the clock:** on computers and tablets the game picker is now a display window like the date and time, listing every game by generation. Scroll it, click a game, or use the arrow keys. Phones keep the drop-down.
- **Bigger displays:** the game picker and the date and time are a little larger.
- **No scroll bar when it all fits:** with every section closed, the IV Checker and Poké Data screens no longer show a scroll bar.
- **Type notes beside the chart:** on wide windows, the type notes for the selected game sit to the right of the weakness and resistance chart.
- **Secret Power and Nature Power fit narrower windows:** the area table drops the separate Kind column (it's shown under each area name instead) so it fits without a sideways scroll bar.

## Install
**Online:** open **scooby5328-design.github.io/iV31** (it updates by itself).

**Windows, Mac or the Linux .tar.gz on 1.2.0 or newer:** iv31 offers this update by itself. Click **Update now**.

**Linux with apt:** `sudo apt update && sudo apt upgrade`

**AppImage:** download the new AppImage below.
