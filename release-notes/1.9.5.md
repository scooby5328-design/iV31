## What's new
- **Windows updates go through the installer:** from the next update on, **Update now** downloads the new installer from GitHub, checks it against its published fingerprint, and runs it for you. iv31 closes, updates and opens again by itself. Because it's a full install, the Start menu and desktop shortcuts, the icon and the version shown in Windows Settings all stay up to date. If you didn't have a desktop shortcut, an update won't add one.
- This version still arrives the old way. The update after it will use the installer.

## Install
**Online:** open **scooby5328-design.github.io/iV31** (it updates by itself).

**Windows, Mac or the Linux .tar.gz on 1.2.0 or newer:** iv31 offers this update by itself. Click **Update now**.

**Linux with apt:** `sudo apt update && sudo apt upgrade`

**AppImage:** download the new AppImage below.
