## What's new
- **Linux.** iv31 now runs on Linux (64-bit Intel/AMD and ARM). Pick the download that suits you:
  - **.deb** for Ubuntu, Debian, Linux Mint, Pop!_OS and similar. Installing it also adds iv31's apt repository, so future versions arrive with your normal system updates.
  - **AppImage** for any distribution: make it executable and run it.
  - **.tar.gz** to run from any folder. This one updates itself like the Windows and Mac versions.
- **Older Macs.** The Mac version now runs on macOS 10.15 Catalina and newer (it needed macOS 14 before). On Catalina, install the latest Catalina and Safari updates first.
- Colors and highlights now show correctly on older Macs and Linux systems whose web engine is a few years old.

## Install
**Windows, already on 1.2.0 or newer (except 1.3.0):** iv31 offers this update by itself. Click **Update now**.

**Windows, new or on 1.3.0 or older:** download **iv31-Setup-1.4.2.exe.zip** below, right-click it, choose **Extract All**, then run the installer.

**Mac, already on 1.4.1:** iv31 offers this update by itself.

**Mac, new:** download **iv31-1.4.2-mac.zip**, double-click it, drag **iv31.app** into **Applications**, then open **Terminal** and run:
```
xattr -dr com.apple.quarantine /Applications/iv31.app
```

**Ubuntu, Debian, Mint (apt):** open **Terminal** and run these lines:
```
curl -fsSL https://raw.githubusercontent.com/scooby5328-design/iV31/apt/iv31-archive-keyring.gpg | sudo tee /usr/share/keyrings/iv31-archive-keyring.gpg > /dev/null
curl -fsSL https://raw.githubusercontent.com/scooby5328-design/iV31/apt/iv31.sources | sudo tee /etc/apt/sources.list.d/iv31.sources > /dev/null
sudo apt update && sudo apt install iv31
```
Or download **iv31_1.4.2_amd64.deb** (ARM: **arm64**) below and open it with your software installer.

**AppImage:** download **iv31-1.4.2-x86_64.AppImage** (ARM: **aarch64**), then in Terminal run `chmod +x iv31-1.4.2-x86_64.AppImage` and `./iv31-1.4.2-x86_64.AppImage`.
