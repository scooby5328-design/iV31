## What's new
- **Folder tabs:** the tabs now run down the left side of the screen like the tabs on a stack of folders. The open tab joins onto its page.
- **One scrollbar:** the Poké Data table and the type chart no longer have their own scrollbar inside the screen. Everything scrolls together, and the column headings stay at the top as you scroll.

## Install
**Online:** open **scooby5328-design.github.io/iV31** (it updates by itself).

**Windows, Mac or the Linux .tar.gz on 1.2.0 or newer:** iv31 offers this update by itself. Click **Update now**.

**Linux with apt:** `sudo apt update && sudo apt upgrade`

**AppImage:** download the new AppImage below.
