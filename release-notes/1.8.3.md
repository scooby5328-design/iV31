## What's new
- **Strong against** column in Poké Data: the types each Pokémon's own type moves hit for 2×.
  - Click one of those types to list the Pokémon of that type.
  - Sort by it to find the Pokémon with the widest coverage.
  - Hide it under **Columns** if you want a narrower table.

## Install
**Online:** open **scooby5328-design.github.io/iV31** (it updates by itself).

**Windows, Mac or the Linux .tar.gz on 1.2.0 or newer:** iv31 offers this update by itself. Click **Update now**.

**Linux with apt:** `sudo apt update && sudo apt upgrade`

**AppImage:** download the new AppImage below.
