## What's new
- **iv31 for Mac.** iv31 now runs on macOS 14 (Sonoma) or newer, on both Intel and Apple Silicon Macs. Download **iv31-1.4.1-mac.zip** below. It updates itself the same way the Windows version does.
- The Mac version has the usual menu bar: Quit (⌘Q), Hide, Copy and Paste, and Minimize.
- Update messages no longer talk about a Windows installer when you're on a Mac.

## Install
**Windows, already on 1.2.0 or newer (except 1.3.0):** iv31 offers this update by itself. Click **Update now**.

**Windows, new or on 1.3.0 or older:** download **iv31-Setup-1.4.1.exe.zip** below, right-click it, choose **Extract All**, then run the installer. If Windows shows "Windows protected your PC", click **More info → Run anyway**.

**Mac:**
1. Download **iv31-1.4.1-mac.zip** below and double-click it. You get **iv31.app**.
2. Drag **iv31.app** into your **Applications** folder.
3. iv31 isn't signed with a paid Apple developer certificate, so macOS blocks it the first time. Open **Terminal** and run:
   ```
   xattr -dr com.apple.quarantine /Applications/iv31.app
   ```
   Or, without Terminal: try to open iv31 once, then go to **System Settings → Privacy & Security** and click **Open Anyway**.
4. Open iv31 from Applications or Launchpad.
