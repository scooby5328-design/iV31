## What's new
- **Smaller, tidier pages:** less empty space everywhere, on the computer and on phones.
- **Pokémon data pages:** EVs it gives and the evolution line now sit in one box under Base stats, with Training focus and Where to find it beside them. The number and buttons at the top are smaller.
- **Controls first, reading last:** every page now starts with the things you use (search, filters, buttons) and the results. Explanations like "How to read it" moved to a notes box at the bottom.
- **Search without scrolling:** typing in Poké Data, Routes or Secret Power keeps the results on screen.
- **Route pages:** the route's details sit beside the mini map.

## Install
**Online:** open **scooby5328-design.github.io/iV31** (it updates by itself).

**Windows:** iv31 offers this update by itself. Click **Update now** and it installs through the installer.

**Mac or the Linux .tar.gz:** iv31 offers this update by itself. Click **Update now**.

**Linux with apt:** `sudo apt update && sudo apt upgrade`

**AppImage:** download the new AppImage below.
