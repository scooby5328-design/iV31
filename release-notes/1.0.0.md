The first release of iv31.

## What's in it
- IV calculator for the full National Pokédex, in Pokédex-number order
- Shows the possible IV range when a single value can't be pinned down yet
- Suggested natures and highlighted key stats for every Pokémon
- EV yield tab with the EVs every Pokémon gives when defeated
- Saves your entries between sessions
- Lightweight Windows app with a per-user installer and full uninstaller

## Install
Download **iv31-Setup-1.0.0.exe.zip** below, right-click it, choose **Extract All**, then run the installer. If Windows shows "Windows protected your PC", click **More info → Run anyway**.

This is an old version. The latest release updates itself, so new users should download that one instead.
