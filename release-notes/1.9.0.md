## What's new
- **Red shell:** the device is now red, with black buttons.
- **32-bit screen:** the blue screen keeps its look but gets a handheld-game style: chunky pixel borders, raised buttons and real accent colours. Section titles are yellow on blue bars, selected options light up yellow, main buttons are red and the **?** help buttons are green.
- **Power button:** the green light next to the iv31 logo turns the screen off. The screen closes like an eye shutting to a bright line in the middle, shrinks to a dot and flickers off. Press it again to turn the screen back on with the start-up screen.

## Install
**Online:** open **scooby5328-design.github.io/iV31** (it updates by itself).

**Windows, Mac or the Linux .tar.gz on 1.2.0 or newer:** iv31 offers this update by itself. Click **Update now**.

**Linux with apt:** `sudo apt update && sudo apt upgrade`

**AppImage:** download the new AppImage below.
