## What's fixed
- **"Cannot connect with the framework core" error.** iv31 1.3.0 showed `NE_CL_IVCTOKN` when it started and couldn't install updates. This is fixed.

## What's new since 1.2.0
Everything from 1.3.0: one game picker for the whole app, a Types tab with a weakness and resistance chart, an EV-lowering berries table, wild locations in the EV yield table, favorites, and types in the IV readout. See the [1.3.0 notes](https://github.com/scooby5328-design/iV31/releases/tag/v1.3.0) for details.

## Install
**On 1.2.0?** iv31 offers this update by itself the next time it starts. Click **Update now**.

**On 1.3.0?** It can't update itself because of this bug. Download **iv31-Setup-1.3.1.exe.zip** below, right-click it, choose **Extract All**, then run the installer once. It installs over 1.3.0 and keeps your saved data.

**New, or on 1.1.0 or older?** Download the installer below and run it. If Windows shows "Windows protected your PC", click **More info → Run anyway**.
