## What's new
- **iv31 is online.** Use it in any browser at **scooby5328-design.github.io/iV31**. It works offline after the first visit, can be installed like an app from your browser, and tells you when a new version is ready.
- **Less repetition, everything in one place:**
  - **Favorites** is now a short list: number, types, the EVs each gives, the 2 stats to focus and the proper nature, with **Data page** and **Check IVs** buttons. The full details live on each Pokémon's data page.
  - **Hidden Power** is all in **Powers → Hidden Power**: the calculator sits above the chart, **Load** on any type fills the calculator, and the current type's row lights up.
  - The **matchup checker** is for type combinations; picking a Pokémon opens its data page, which already shows its matchups.
  - The EV calculator now uses the full width of the IV Calculator tab.
- **Faster and tidier:** tables fit the screen with less work, about 130 unused or overridden style rules were removed, and repeated code was merged.
- **Accessibility:** better contrast on the day screen, type chart headings are proper buttons for keyboards and screen readers, and the **?** on folded panels no longer sits inside the fold button.
- Click sounds only start after your first click or key press, as browsers require.

## Install
**Online:** open **scooby5328-design.github.io/iV31**.

**Windows, Mac or the Linux .tar.gz on 1.2.0 or newer:** iv31 offers this update by itself. Click **Update now**.

**Linux with apt:** `sudo apt update && sudo apt upgrade`

**AppImage:** download the new AppImage below.
